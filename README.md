# Route-and-schedule-adjustment-for-liner-shipping-service-under-anticipated-disruption-events
This repository provides the computational instances and detailed results used in the numerical experiments of the paper “Route and schedule adjustment for liner shipping service under anticipated disruption events.”

The repository includes input data for four computational cases and their corresponding results. Each case contains 50 instances generated from stochastic scenarios of random delay times, together with additional instances for the sensitivity analyses. The Instance and Result folders contain the input data and computational results, respectively, with README files describing the folder structure and file naming conventions.
