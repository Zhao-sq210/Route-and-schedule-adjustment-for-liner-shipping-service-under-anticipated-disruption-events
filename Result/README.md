This folder contains the computational results corresponding to the instances in the Instance folder.
The results are organized into subfolders according to the same case and parameter-setting structure as the instance data.

For example: "R_C1_0.5_0.4_350_21000" denotes the results for the Case 1 parameter setting with:
0.5 = Unit freight revenue for shipping demand;
0.4 = Unit penalty rate for unserved demand;
350 = Bunker fuel price;
21000 = Vessel capacity.

Each result file corresponds to one instance in the Instance folder. For example:
R_C1_0.5_0.4_350_21000_w1.xlsx
corresponds to:
C1_0.5_0.4_350_21000_w1.xlsx

The suffix w1–w50 identifies the corresponding stochastic scenario. Each result file contains the computational results obtained for the corresponding instance.
